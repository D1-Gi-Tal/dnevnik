# Дневник тренировок

Приложение-дневник: план, факт, утренние показатели, аналитика. Данные хранятся в Google Таблице владельца,
в этом репозитории только код — ни данных, ни ключа здесь нет.

Обновление: заменить index.html (Add file → Upload files) и нажать Commit changes. Данные при этом не меняются.
